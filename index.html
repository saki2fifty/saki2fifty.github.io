LenzForge Studio

Real-time AR.

A local Windows AR studio that turns a camera feed into an interactive workspace. Built on Godot, it combines live face tracking, physics-based beards and mustaches, 3D grooming, and visual effects.

  • Shape facial hair on a rotatable mannequin, with native strand physics and interactive clippers.
  • Apply background and facial effects, then share the composed feed through a Windows 11 virtual camera.

PROJECT / 02In development

F.O.R.G.E.

Flecs-Oriented Runtime & Game Editor

A native C++20 game engine and editor for building scenes, writing gameplay, and exporting standalone games. Its entity-component-system architecture centers on Flecs, with Windows and Direct3D 12 as the first editor target.

  • Author scenes and prefabs, edit C++ components and systems, and test gameplay in a separate Play process.
  • Work with materials, skeletal animation, physics, and asset importing in an integrated editor.
